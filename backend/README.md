# Kova App - Backend

This directory contains the server-side logic and API for the Kova App.

## Technologies Used
* **Node.js:** Server runtime environment
* **Express.js:** Web framework for routing and handling requests
* **JavaScript:** Core backend language

## How to Run Locally
To run this server, you will need to have Node.js installed on your machine.

1. Open your terminal and navigate into this `backend` directory.
2. Install the necessary dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   node server.js
   ```
