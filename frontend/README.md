# Kova App - Frontend

This directory contains the user interface and client-side logic for the Kova App. 

## Technologies Used
* **HTML5:** Page structure and layout
* **CSS3:** Styling and responsive design
* **Vanilla JavaScript:** DOM manipulation and client-side functionality

## How to Run Locally
Because this frontend is built with vanilla web technologies, no build step or package manager is required. 
1. Clone the repository.
2. Navigate to this `frontend` folder.
3. Open `index.html` directly in any modern web browser.
